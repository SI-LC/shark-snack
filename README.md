# Shark Snack

A friendly shark game for young children. Catch fish, dodge jellyfish, answer bonus questions and win prizes. An orca whale helps eat jellyfish on levels 1, 11 and 12. Level 7 brings bubble boosts and level 10 brings sharp teeth for biting jellyfish and tough fish. Reach level 20 to start raising an army of baby sharks, then grow all 8 to win.

## Play

Open `index.html` in a browser. Keep `voice.js` in the same folder, because it holds the spoken questions.

## Change the game

The settings and question lists are near the top of the script in `index.html`.

After adding questions, run `python3 make_voice.py` on a Mac to record them. If you change how the generated questions are worded, change `make_voice.py` to match.
